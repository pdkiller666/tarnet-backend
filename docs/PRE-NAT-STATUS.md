**Чего пока НЕТ (и это ожидаемо):**

```
/p2p/status → connections: 1, worker_addresses: [], channels: 0
```

Соединение есть, **канала задач нет**. Это ровно тот случай, который описан в
`NAT-TEST.md` §4.2: `worker_addresses: []` при `connections: 1` значит «кто-то
подключён, но авторизованного канала нет». Пока воркер не запущен на машине
Владельца, канала и не будет — это состояние до теста, а не дефект.

## 2. Что нужно от Владельца

Порядок ровно такой — каждый шаг проверяем, а не «должно работать»:

1. **Взять ПК с домашним интернетом** (не VPS, не тот же хост, где мост).
2. **Открыть** `https://v1107336.hosted-by-vdsina.com/app/` → установщик.
3. **Проверить транспорт** до запуска: `cd ~/.tarnet/p2p-node && npm ci --omit=dev`,
   затем `node -e "import('libp2p').then(()=>console.log('libp2p ok'))"` → `libp2p ok`.
   Если этого не сделать, тест провалится **не по вине NAT**.
4. **Запустить с флагом:** `./start.sh --test-p2p` (Windows: `start.cmd --test-p2p`).
5. **Скопировать из лога** строки от `[p2p-worker] bootstrap:` до
   `[p2p-worker] hello отправлен от 0x…`.
6. **Прислать отчёт** по `NAT-TEST.md` §8: лог, вывод `check-autostart.js --json`,
   `bridge.connections` + `bridge.tasks.channels`, и **тип подключения**
   (прямой / CGNAT `100.64.x.x` / VPN). Без пункта 4 отчёт недоказуем.

Одна оговорка, которую нельзя пропустить: **отсутствие публичного входящего
адреса — норма**, а не отказ. Критерий успеха — `connections` **и** `channels`
одновременно, а не «адрес в реестре».

## 5. Найденный дефект (исправлен в этой версии)

`scripts/migrate-legacy-jsonl.js` считал шифром **только** `enc:v1:`. С `2.26.0`
датасеты пишутся как `enc:v2:` (с AAD), поэтому скрипт видел 34 уже
зашифрованных файла как открытый текст и на `--apply` зашифровал бы **сам
шифротекст**: расшифровка вернула бы `enc:v2:…` вместо промпта, без единой
ошибки в выводе. Исправлено: распознаются оба формата, `--apply` пишет v2 с
AAD `${promptHash}:${field}`. Проверено: dry-run `366 / 56` совпадает с
независимым подсчётом; round-trip v2 читается, чужой и пустой AAD отвергаются.
