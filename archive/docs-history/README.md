**Почему НЕ удалены.** Отчёт — это свидетельство: он показывает, что думали в тот день и
какими словами это называли. `PROJECT-HISTORY` пересказывает; отчёт даёт первоисточник.
Разница между «архив» и «удалено» — возможность проверить пересказ.

**Правило для `docs/`.** Файл попадает сюда, когда его факты целиком есть в каноническом
документе И на него не ссылается ни один живой документ. Ссылки в `PROJECT-HISTORY`,
`PROJECT-MAP`, `ROADMAP`, `MANIFEST` обновлены в том же коммите, что и перенос: перенос без
правки ссылок оставил бы битые пути.
