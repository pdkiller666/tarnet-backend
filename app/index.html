Быстрый путь

Скачайте установщик и запустите двойным кликом — он сам поставит Node.js и Ollama, скачает модель и запустит воркер. Ваш адрес уже внутри.

Windows (.bat) macOS / Linux (.command)

Windows — скачали, дважды кликнули, готово.
macOS — браузер сохраняет файл без права на запуск и помечает его карантином. Один раз перед запуском в Терминале: chmod +x ~/Downloads/install-tarnet-worker.command, потом правый клик → «Открыть». Обойти это кодом нельзя — так работает Gatekeeper.

После установки на рабочем столе появится ярлык TarNet. Двойной клик запускает воркер снова — установщик повторно не нужен. Мастер установки говорит по-английски: русский текст в консоли Windows превращается в нечитаемые символы, поэтому подписи оставлены латиницей, а вся эта инструкция — здесь. Если ярлык создать не удалось (ограничения политики Windows), запускайте вручную: %LOCALAPPDATA%\TarNet\start.cmd. Закрытие окна PowerShell останавливает воркер — это ожидаемо, ярлык поднимает его обратно.

Создать TarNet ID

Агенты привязаны к аккаунту TarNet ID. Ключ выводится на этом устройстве из мастер-энтропии — на сервер уходит только публичный ключ.

Энтропия сохраняется в localStorage этого браузера: без неё HITL-подпись требовала бы вводить фразу на каждое подтверждение. Это компромисс стенда, а не боевая схема хранения.
